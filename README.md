
# Subscription Management System

A web-based Subscription Management System designed to help organizations manage subscription-based products, recurring billing, invoices, payments, taxes, discounts, and customer subscriptions.

## Project Overview

This project provides a centralized platform for managing the complete subscription lifecycle, including:

- Product Management
- Recurring Billing Plans
- Customer Subscriptions
- Quotation Generation
- Invoice Generation
- Payment Tracking
- Tax & Discount Management
- Reports and Dashboards

The system supports three user roles:

- **Admin** – Manages products, recurring plans, taxes, discounts, and internal users.
- **Internal User** – Creates subscriptions, generates invoices, and records payments.
- **Customer (Portal User)** – Views subscriptions, invoices, and payment history.
